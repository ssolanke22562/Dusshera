# 🏹 Happiest Dussera To You • Sarthak Solanke and Family 🌸

A breathtaking, animation-loaded festive web application celebrating the auspicious occasion of **Vijayadashami (Happy Dussehra)** with the triumph of Good over Evil, dedicated to **Sarthak Solanke and Family**.

![Dussehra Preview](/public/assets/dussehra_hero.jpg)

---

## ✨ Features & Visual Animations

- 🌟 **Shimmering Royal Typography**: Features the exact requested greeting: **"Happiest Dussera To You"** in animated liquid gold metallic shimmer.
- 📜 **Warmest Regards**: **"Warmest Wishes & Divine Regards, Sarthak Solanke and Family"** in elegant glowing calligraphy with royal seal.
- 🏹 **Interactive Divine Bow & Arrow Arena**:
  - Pull and drag the celestial string of Lord Rama's *Kodanda* bow backwards to build energy, or click *"Release Divine Arrow"*.
  - Watch the blazing *Brahmastra* streak across the sky with flame trails and sparks to strike the 10-headed Ravana effigy.
  - Triggers massive firework explosions, screen shake, burning effigy effect, and the victory banner: *॥ अधर्म पर धर्म की विजय ॥*.
- 🍃 **Sona Vrusthi (Gold Leaves & Marigold Petals Engine)**:
  - High-performance canvas particle system simulating fluttering Marigold petals and authentic Maharashtrian/Indian Apta (Shami) gold leaves.
  - Interactive click/tap anywhere on screen generates bursts of flower petals and gold.
- 🪔 **5 Auspicious Diyas Lighting Ritual**:
  - Click to light clay diyas representing *Arogya* (Health), *Samriddhi* (Wealth), *Vijaya* (Victory), *Shanti* (Peace), and *Gyan* (Wisdom), revealing their sacred blessings.
- 🔔 **Synthesized Web Audio Experience**:
  - Authentic temple bells (*Ghanta* harmonics), celebratory firework crackles, bow whoosh, and meditative ambient Indian drone (*Tanpura*). Works offline with zero broken audio links!
- 💌 **Personalization & Social Sharing**:
  - Add recipient names (e.g. `?to=Sharma+Family`).
  - One-tap WhatsApp sharing with pre-formatted festive message.
  - Copy greeting link with toast notification.

## 🚀 How to Run Locally

1. Clone or open the folder:
   ```bash
   cd Dussers
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser.

## 🌐 Deploy to Vercel (1-Click & Free)

This project is pre-configured with `vercel.json` and optimized for instant zero-configuration deployment on Vercel.

### Option 1: Deploy with Vercel CLI (Fastest)

Run the following command in the project directory:
```bash
npx vercel
```
Follow the interactive prompts:
- Set up and deploy? **Yes (`y`)**
- Which scope? **Select your account**
- Link to existing project? **No (`n`)**
- What's your project's name? **dussehra-wishes**
- In which directory is your code located? **`./`**
- Want to modify these settings? **No (`n`)**

Your live URL will be ready in seconds!

### Option 2: Deploy via GitHub & Vercel Dashboard

1. Push this folder to a GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "Festive Dussehra greeting website"
   git branch -M main
   git remote add origin https://github.com/<YOUR_USERNAME>/<REPO_NAME>.git
   git push -u origin main
   ```
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import your repository. Vercel automatically detects Vite with:
   - **Framework Preset**: `Vite`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
4. Click **Deploy**. Your website is live worldwide! 🚀
